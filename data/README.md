# Instructions for Dataset Acquisition and Provenance

## 1. Primary Source
The dataset utilized in this project is sourced from:
- **Title:** Crop Yield Data with Soil and Weather Dataset
- **Publisher / Curator:** Anshu Mishra (`anshumish`) on Kaggle
- **Underlying Primary Provenance:** Directorate of Economics and Statistics, Ministry of Agriculture & Farmers Welfare (Government of India) paired with regional India Meteorological Department (IMD) weather records.
- **Kaggle URL:** [https://www.kaggle.com/datasets/anshumish/crop-yield-data-with-soil-and-weather-dataset](https://www.kaggle.com/datasets/anshumish/crop-yield-data-with-soil-and-weather-dataset)

## 2. Included Files in `data/`
1. `crop_yield.csv`: Historical crop production and yield observations across Indian states (1997–2020).
2. `state_soil_data.csv`: State-level topsoil macronutrient profiles (Nitrogen, Phosphorus, Potassium in kg/ha, and Soil pH).
3. `state_weather_data_1997_2020.csv`: Annual meteorological metrics (annual rainfall in mm, average temperature in °C, and average relative humidity in %).
4. `processed_crop_yield_data.csv`: Cleaned, unified dataset generated by `train_model.py` after resolving string spaces, aligning records, and isolating unit-divergent outliers (19,517 records).

## 3. How to Re-fetch or Update the Raw Data
If you ever need to re-download the dataset directly from Kaggle via Python:

```bash
# 1. Install kagglehub (already in environment)
pip install kagglehub

# 2. Run the acquisition script in Python:
python -c "import kagglehub, shutil, os; path = kagglehub.dataset_download('anshumish/crop-yield-data-with-soil-and-weather-dataset'); [shutil.copy(os.path.join(path, f), os.path.join('data', f)) for f in os.listdir(path) if f.endswith('.csv')]"
```

## 4. Target Variable and Units
- **Target Variable:** `yield` (Historical Crop Yield)
- **Units:** `Tonnes per Hectare (t/ha)` ($\text{Production in Tonnes} / \text{Cultivated Area in Hectares}$)
- *Note:* In Indian agricultural datasets, coconut production is quantified in *thousands of nuts per hectare* rather than metric tonnes. To uphold absolute unit consistency across all features, Coconut was filtered out of the continuous tonne-based regression benchmark.
